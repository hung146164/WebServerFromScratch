Upload Parser

Tải Lên File (POST Upload)

Gửi file sử dụng chuẩn định dạng multipart/form-data. Trình phân tách nhị phân của C++ sẽ trích xuất tên file và ghi đè xuống thư mục lưu trữ.

Hỗ trợ: .html, .htm, .css, .js, .json, .xml, .txt, .png, .jpg, .jpeg, .gif, .svg, .ico, .webp, .woff, .woff2, .ttf, .pdf, .zip
Hạn mức dung lượng: ≤ 50 KB
Chưa tải file lên. Thư mục lưu trữ: /www/upload/
Arena JSON Parser

Chưa chạy kiểm thử JSON.
