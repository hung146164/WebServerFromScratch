Kiến trúc Hệ thống (Multi-Reactor)

WebServerVdt sử dụng mô hình sự kiện phi tuần tự thay thế hoàn toàn cho mô hình Thread-per-connection cổ điển:

  • Kernel Load-balancing: Dùng SO_REUSEPORT phân chia IP băm xuống các Worker.
  • Thread Pinning: Khóa cứng luồng Worker vào nhân CPU (Core 0, Core 1...) tăng hit cache L1/L2.
  • Epoll Loop: Sự kiện không chặn, mỗi Worker xử lý hàng vạn kết nối đồng thời.
  • Zero-copy Sendfile: Phục vụ file từ Kernel space không qua User space RAM.

Cấu hình Server hiện tại

Max Epoll Events:50

Max Limit per IP:10 conn
