Kiểm Thử Tương Tác

Kiểm Thử Tính Năng

Thực hiện các truy vấn đặc thù để kiểm thử các cơ chế nâng cao được lập trình trong nhân máy chủ C++.

HTTP Caching

Bộ Nhớ Đệm 304

Kiểm thử cơ chế Cache dựa trên header Last-Modified và If-Modified-Since để tối ưu hóa lưu lượng truyền tải.

Chưa chạy kiểm thử. Nhấp "Request 1" để lấy dấu thời gian Last-Modified.
Partial Content

Tải Từng Phần 206

Kiểm tra tính năng hỗ trợ tải tiếp (Resume Download/IDM) qua Header Range: bytes=start-end.

Chưa chạy kiểm thử.
Upload Parser

Tải Lên File (POST)

Gửi file sử dụng chuẩn định dạng multipart/form-data. Trình phân tách nhị phân của C++ sẽ trích xuất tên file và ghi đè xuống thư mục lưu trữ.

Giới hạn: tối đa 60 KB. Định dạng hỗ trợ: .html, .css, .js, .json, .txt, .png, .jpg, .gif, .pdf, .zip
Chưa có file nào được tải lên.
Security Tunnel

Đường Truyền Bảo Mật RC4

Mã hóa dữ liệu tại client bằng mật mã RC4 trước khi gửi đi. Server giải mã, xử lý và mã hóa ngược kết quả trước khi trả về.

Chưa chạy kiểm thử bảo mật. Khóa mã hóa cứng: VDTSecretKey
Rate Limiter

Chống Spam 429

Bắn hàng loạt request song song trong 1 giây để vượt ngưỡng bảo vệ (20 req/s). Server sẽ lập tức trả về mã lỗi 429 Too Many Requests.

Chưa kích hoạt.
Zero-Copy Sendfile

Tải File Khủng (1.5GB)

Truyền dữ liệu trực tiếp từ đĩa cứng sang card mạng ở không gian nhân (Kernel Space) bằng sendfile, không tốn tài nguyên RAM của Server hay Client. Tải trực tiếp về thư mục Downloads của bạn.

Tải File 1.5GB Về Máy
Gợi ý: Nhấn chuột để kích hoạt download gốc của trình duyệt (xem tiến độ tải ở mục Download của Chrome/Firefox).
Arena JSON Parser

Phân Tích Cú Pháp JSON 10K Nodes

Kiểm thử bộ phân tích cú pháp JSON Zero-copy cấp phát tĩnh (10,000 nodes). Hỗ trợ nạp nhanh dữ liệu mẫu và kịch bản gửi JSON khổng lồ để kích hoạt cơ chế bảo vệ.

Chưa có dữ liệu nào được phân tích.
